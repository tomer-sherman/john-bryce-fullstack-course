# CipherMind 🛡️

A cybersecurity knowledge engine — ask a question, and the answer is retrieved (RAG) from a cybersecurity knowledge base and decrypted by AI.

## Stack

- **Frontend:** React + TypeScript + Vite, react-hook-form, axios
- **Backend:** Node + Express + LlamaIndex (RAG) + OpenAI

## Run

```
npm start
```

Backend must be running on http://localhost:4000
